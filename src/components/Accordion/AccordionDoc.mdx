### When to use

Use the Accordion component when you need to organise related content into collapsible sections. Accordions help reduce visual clutter and allow users to focus on the information most relevant to them.

#### Frequently Asked Questions

Accordions are commonly used for FAQ sections where users may only need answers to specific questions.
For example:

- Product FAQs
- Service information
- Booking information

#### Content Organisation

Use accordions when presenting secondary or supplementary information that does not need to be visible immediately.For example:

- Technical specifications
- Policies and procedures
- Additional details

#### Space-Constrained Layouts

Use accordions when screen space is limited and displaying all content at once would make the page difficult to scan. Avoid using accordions when users need to compare multiple sections simultaneously, as hidden content can make comparison more difficult.

### Accessibility

<div className="docsAccessibility">

#### Semantic usage

- The component uses native `<details>` and `<summary>` elements.
- Native accordion behaviour provides built-in keyboard interaction.

#### Keyboard interaction

Users can:

- Tab to an accordion summary
- Press Enter to toggle a section
- Press Space to toggle a section

#### Clear headings

Accordion titles should clearly describe the content contained within each section. For example:

- What should I bring?
- How long does the tour last?
- Are food and drinks provided?

#### Content organisation

- Keep section titles concise and descriptive.
- Group related information together.
- Avoid placing critical information inside collapsed sections if all users must see it immediately.

</div>
