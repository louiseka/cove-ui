# Input

<div className="docsHero">
  A reusable form input component with accessible labeling and support for
  multiple input types.
</div>
---

## Live Examples

<div className="docsExamples">

    <Input id="name" name="first-name" type="text">
      Your first name
    </Input>


    <Input id="age" name="age" type="number">
      Quantity
    </Input>

<Input
  id="email-address"
  name="email-address"
  type="email"
  pattern=".+@example\.com"
  required={true}
>
  Your email address
</Input>

    <Input id="mobile-number" name="mobile number" type="tel" pattern="^(\+44\s?7\d{3}|07\d{3})\s?\d{3}\s?\d{3}$">
      Your UK mobile number
    </Input>

</div>

## When to use

Use these inputs within a form element with button type submit.

## Props

<div className="docsTable docsProps">

| Prop     | Type                                   | Default | Description                                 |
| -------- | -------------------------------------- | ------- | ------------------------------------------- |
| children | React.ReactNode                        | —       | Label text for input                        |
| id       | string                                 | —       | Used for input id and label htmlFor linking |
| name     | string                                 | —       | Name used in form submission                |
| type     | "text" \| "number" \| "email" \| "tel" | "text"  | Input field type                            |
| required | boolean                                | false   | Marks input as required                     |
| pattern  | string                                 | —       | A regex that the input's value must match   |

</div>
