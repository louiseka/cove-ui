## Props

<div className="docsTable docsProps">

| Prop        | Type   | Default | Description                      |
| ----------- | ------ | ------- | -------------------------------- |
| img         | string | —       | The source URL of the card image |
| imgAlt      | string | —       | Alternative text for the image   |
| title       | string | —       | Title displayed in the card      |
| description | string | —       | Main descriptive text content    |
| buttonText  | string | —       | Text displayed inside the button |
| link        | string | —       | URL for the card link            |
| linkText    | string | —       | Text displayed for the link      |

</div>
